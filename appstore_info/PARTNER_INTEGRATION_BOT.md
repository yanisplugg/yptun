# Интеграция с ботом @quofortpostbot и монетизация через РФ ИП

В этом документе детально описана архитектура и план интеграции YPtun с Telegram-ботом `@quofortpostbot`, принадлежащим одногруппнику (оформленному как ИП в РФ), с соблюдением правил Apple App Store.

---

## 1. Риски модерации Apple (App Store Review Guideline 3.1.1)

### Почему нельзя ставить прямую кнопку «Купить» в приложении:
1. **Правило 3.1.1 (In-App Purchase):**  
   Apple требует, чтобы любые платные цифровые услуги и подписки, открывающие доступ к функциям на iOS, продавались **исключительно** через внутриигровые покупки Apple In-App Purchase (с комиссией Apple 15–30%).
2. **Запрет на Anti-Steering:**  
   Кнопки вида «Купить подписку за 150 ₽», ведущие на сайт, в Telegram-бот или на перевод СБП, гарантированно вызывают отказ модератора (*"Guideline 3.1.1 - Business - Payments - In-App Purchase"*).
3. **Санкционные ограничения Apple Pay:**  
   Официальные покупки Apple IAP в России сейчас не работают с большинством банковских карт. Поэтому продавать подписку через бота по СБП/картам РФ для российских пользователей в сотни раз удобнее и выгоднее.

## 2. Безопасные схемы интеграции (Рекомендованный подход)

### Вариант 1: Схема «Чистый клиент» + Нейтральная плашка (Самый безопасный и надежный)

Это модель, по которой работают **все** ведущие VPN-клиенты в App Store (*Sing-box, Streisand, V2Box, Foxtray, Shadowrocket*):

1. **В приложении YPtun:**
   - Приложение является **100% бесплатным**. В нем нет каталога товаров, ценников, корзины и слов «Купить/Оплатить».
   - В настройках или внизу списка локаций добавляется нейтральная строка/плашка:
     > **«Сообщество и поддержка»** ➔ ссылка `https://t.me/quofortpostbot`  
     > *(или «Официальный бот с серверами» / «Получить тестовый доступ»)*.
   - **Чего на плашке быть НЕ должно:** слов *«Купить»*, *«Тарифы»*, *«Оплата»*, *«Скидка»*, *«Цены»*.
   - **Что должен отдавать бот `@quofortpostbot` при старте:**
     При нажатии `/start` бот должен приветствовать пользователя нейтральным экраном с разделами:
     - ℹ️ *О сервисе*
     - ❓ *Инструкция по настройке*
     -  *Попробовать бесплатно (Тестовый доступ)*
     -  *Личный кабинет / Подписка*  
     *(Если бот с первого же экрана не кричит капсом «ПЕРЕВЕДИ ДЕНЬГИ НА КАРТУ», модератор Apple сочтет его справочно-сервисной поддержкой).*

2. **В Telegram-боте `@quofortpostbot` (Монетизация через РФ ИП):**
   - Пользователь оплачивает доступ внутри Telegram через эквайринг одногруппника (ЮKassa, Prodamus, Robokassa или Тинькофф Оплата). Деньги падают на расчетный счет ИП, клиенту в Telegram уходит фискальный чек по 54-ФЗ.
   - После успешной оплаты бот присылает сообщение с красивой кнопкой:
     ```
     [  Подключить в YPtun (1 клик) ]
     ```
   - Эта кнопка ведет на нативный диплинк:
     `yptun://import/<ссылка_на_подписку>`

3. **Мгновенный импорт в YPtun:**
   - Пользователь тапает кнопку в Telegram ➔ iOS сразу запускает YPtun ➔ приложение подхватывает ссылку через `OlcboxIosApp.swift:handleUrl` и добавляет серверы в список ➔ пользователь жмет «Подключиться».

### Вариант 2: Динамический переключатель (Remote Config)

Если в будущем захочется сделать внутри YPtun более явный рекламный баннер:

1. Создается файл конфигурации на GitHub Pages (например, `https://zamotashka.github.io/olcvpn-client/config.json`):
   ```json
   {
     "show_partner_banner": false,
     "banner_title": "Серверы от Quofort",
     "banner_url": "https://t.me/quofortpostbot"
   }
   ```
2. **При подаче новой версии на модерацию Apple (2–3 дня):**  
   Флаг `"show_partner_banner"` переводится в `false`. Модераторы видят строгое приложение без баннеров.
3. **После публикации в App Store (Ready for Sale):**  
   Флаг меняется на `true`. Баннер моментально активируется у всех пользователей без необходимости выпускать новое обновление через App Store.

## 3. Техническая спецификация для бота одногруппника

Чтобы бот корректно работал с YPtun, разработчику бота нужно реализовать:

1. **Формат диплинка для одной ноды:**
   ```
   yptun://import/vless://uuid@host:port?security=reality&...#LocationName
   ```
   *(ссылка должна быть URL-encoded).*

2. **Формат диплинка для подписки (несколько серверов):**
   ```
   yptun://import/https://your-domain.ru/api/sub?token=xyz
   ```

3. **Telegram Inline Button:**
   В Telegram Bot API кнопка создается как:
   ```python
   InlineKeyboardButton(
       text="🚀 Подключить в YPtun", 
       url=f"https://t.me/share/url?url={deeplink}" # или прямая ссылка yptun://import/...
   )
   ```

## 4. Юридическая сторона (РФ ИП одногруппника)

- **ОКВЭД:** Подходят `62.01` (Разработка ПО), `62.09` (Прочая деятельность в области ИТ) или `63.11` (Деятельность по обработке данных и предоставлению услуг по размещению информации).
- **Налогообложение:** УСН «Доходы» 6% или АвтоУСН.
- **Эквайринг:** ЮKassa / Robokassa / Prodamus / PaySelection с подключением Telegram Bot Payments или интеграцией через платёжную ссылку.
- **Для Apple:** Так как продажи идут в Telegram, а YPtun распространяется бесплатно, перед Apple не возникает никаких налоговых или отчетных обязательств.
